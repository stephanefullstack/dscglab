Comment s'entraîner

  1. Imprimez le sujet, ou affichez-le seul : les corrigés sont sur une page séparée.
  2. Composez dans le temps indiqué, avec la liste des comptes et une calculatrice sans mémoire. Écrivez vos hypothèses quand l'énoncé l'exige.
  3. Notez-vous avec le barème du corrigé, item par item. Les réponses tolérées y sont indiquées.
  4. Relisez la rubrique des erreurs fréquentes : elle reprend les reproches des rapports du jury.

Ce que vous lisez

Les cas sont originaux. Les corrigés citent les textes applicables (plan comptable général, règlement ANC 2020‑01, IFRS, code de commerce, normes d'exercice professionnel, lignes directrices de la H2A) et indiquent par la mention [V] les règles vérifiées sur le texte officiel. Les calculs, les écritures et les barèmes ont été contrôlés par un outil de vérification automatique. Comme le rappellent les corrigés officiels, il n'est pas attendu du candidat qu'il cite les numéros d'articles ou de normes.

Supports d'entraînement non officiels, sans lien avec le ministère ni avec les organisateurs de l'examen. Réglementation applicable au 31 décembre 2026. Les corrigés ont été contrôlés par un outil de vérification automatique ; ils peuvent néanmoins comporter des erreurs.
